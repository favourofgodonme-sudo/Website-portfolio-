Excel Data Analysis

A complete Excel data analysis project focused on Supreme Supermarket. Titanic Data Analysis

A detailed exploratory data analysis of the Titanic dataset, using Python to investigate passenger survival patterns and the relationships between key variables such as passenger class, age, fare, family relationships and survival status. The project combines statistical analysis and clear visual storytelling to turn historical passenger data into meaningful insights and actionable observations.

Power BI Data Analysis

An interactive Power BI business intelligence project built with the Adventure Works dataset. I transformed complex sales, budget, territory and product information into an easy-to-read dashboard that reveals important trends and performance indicators. The project demonstrates how Power BI can turn raw data into interactive insights that support smarter reporting and data-driven decision-making.
